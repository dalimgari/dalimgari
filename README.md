# Dalimgari Website

Bengali-first, mobile-first community website for Dalimgari.

## Foundation

- React + Vite
- Supabase
- GitHub Pages
- GitHub Actions
- No Firebase

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Supabase credentials belong in local environment variables. Never commit service-role or secret keys.
