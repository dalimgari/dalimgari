DALIMGARI WEBSITE — MASTER SPEC & REQUIREMENTS

This folder contains the compact, topic-based Master Specification and Requirements for the Dalimgari Website.

Each TXT file is a short-form reference: important requirements are retained in compact form instead of repeating long explanations.

Documentation rule:
DEFINED = requirement/specification.
CONFIRMED = verified from actual project.
SHEET INVENTORY = supplied spreadsheet inventory; not automatically actual schema.
VERIFICATION REQUIRED = must be checked against project/code/database/config.

Original specification and final spreadsheet integrity must be preserved. Approved additions are additive only.
