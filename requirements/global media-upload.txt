# Dalimgari Website — Final Requirements

## 6. global media-upload.md

Global Media Upload system-এ শুধুমাত্র ২টি method থাকবে:

1. Photo অথবা Video Upload
2. Select Existing Photo অথবা Video

### Upload

- নতুন Photo বা Video Supabase Storage-এ upload হবে।
- Upload সফল হলে generated media URL system নিজে ব্যবহার করবে।
- User custom URL/link দিয়ে media add করতে পারবে না।

### Select

- আগে upload করা media database/storage থেকে নির্বাচন করা যাবে।
- নতুন upload না করেও existing media ব্যবহার করা যাবে।
- প্রয়োজন অনুযায়ী Photo এবং Video আলাদা করে নির্বাচন করা যাবে।

### Method rule

- একই media input-এর ক্ষেত্রে একই সময়ে দুই method ব্যবহার করা যাবে না।
- Upload অথবা Select—একটি method ব্যবহার করতে হবে।

### UI

- Upload interface mobile-friendly হবে।
- Upload button অপ্রয়োজনীয়ভাবে বড় হবে না।
- Media selection interface responsive হবে।
