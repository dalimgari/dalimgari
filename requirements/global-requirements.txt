# Dalimgari Website — Final Requirements

## 1. global-requirements.md

- Website-এর সব data database-এ নির্ধারিত structure অনুযায়ী সংরক্ষিত হবে।
- প্রতিটি user এবং admin-এর জন্য system-generated unique UID থাকবে।
- UID user বা admin নিজে পরিবর্তন করতে পারবে না।
- User-এর নিজস্ব data তার UID-এর সাথে সম্পর্কিত থাকবে।
- Data ownership এবং authorization অনুযায়ী data access নিয়ন্ত্রণ হবে।
- একজন সাধারণ user অন্য user-এর private data দেখতে পারবে না।
- Admin Dashboard-এর অনুমোদিত অংশ থেকে user data দেখা ও পরিচালনা করা যাবে।
- নতুন data type ভবিষ্যতে সহজে যুক্ত করা সম্ভব হতে হবে।
- Code, component, section, function, table, API এবং requirement-এর naming যতটা সম্ভব সামঞ্জস্যপূর্ণ রাখতে হবে।
- কোনো existing name পরিবর্তনের আগে তার সাথে সম্পর্কিত requirement এবং code dependency বিবেচনা করতে হবে।
- Website-এর কোনো functional requirement অন্য requirement-এর সাথে conflict করলে নির্দিষ্ট functional requirement এবং security rule অগ্রাধিকার পাবে।
