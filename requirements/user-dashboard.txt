# Dalimgari Website — Final Requirements

## 12. user-dashboard.md

User login করার পর শুধুমাত্র User Dashboard দেখতে পারবে।

### Display

- Profile Photo
- Name
- Date of Birth
- Address
- Mobile Number
- Email

### Actions

- Edit Profile
- Change Password
- Delete Account

### Rules

- Password কখনো display করা যাবে না।
- Change Password-এর মাধ্যমে password পরিবর্তন করা যাবে।
- User নিজের profile information edit করতে পারবে।
- Account creation-এর সময় দেওয়া অথবা সর্বশেষ updated information দেখানো হবে।
- Delete Account action-এর আগে confirmation নিতে হবে।
- Account delete করার পর authentication access বন্ধ হবে।
- User-generated data-এর deletion/retention behavior database relationship অনুযায়ী নির্ধারিত হবে এবং orphaned data তৈরি করা যাবে না।
