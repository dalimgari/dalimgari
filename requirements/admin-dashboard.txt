# Dalimgari Website — Final Requirements

## 11. admin-dashboard.md

- কোথাও “Admin Panel” নাম ব্যবহার করা যাবে না।
- সর্বত্র **Admin Dashboard** নাম ব্যবহার করতে হবে।
- Admin Dashboard website-এর administrative information এবং management functionality নিয়ন্ত্রণ করবে।
- Admin Dashboard responsive হবে।
- বিভিন্ন module নির্দিষ্ট requirement অনুযায়ী আলাদাভাবে পরিচালনা করা যাবে।
- Buttons, inputs এবং অন্যান্য interface element প্রয়োজন অনুযায়ী compact থাকবে।
- Admin Dashboard-এর access শুধুমাত্র authorized admin role-এর জন্য থাকবে।
- সাধারণ user Admin Dashboard access করতে পারবে না।
