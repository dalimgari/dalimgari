# Dalimgari Website — Final Requirements

## 8. authentication.md

- Website-এর জন্য একটি unified Login system থাকবে।
- Login credentials এবং assigned role/permission অনুযায়ী dashboard নির্ধারিত হবে।
- Admin role-এর account → Admin Dashboard।
- সাধারণ user account → User Dashboard।
- User login-এর জন্য registered email অথবা mobile number ব্যবহার করা যাবে।
- Password required হবে।
- Account না পাওয়া গেলে user-কে account তৈরি করার নির্দেশনা দেখানো হবে।
- Website থেকে তৈরি হওয়া নতুন account সাধারণ user role দিয়ে তৈরি হবে।
- Admin role শুধুমাত্র authorized system/database configuration অনুযায়ী নির্ধারিত হবে।
- Password কখনো plaintext হিসেবে সংরক্ষণ করা যাবে না।
- Password সরাসরি কোনো dashboard-এ দেখানো যাবে না।
- Authentication এবং authorization আলাদা করে enforce করতে হবে।
- Blocked user login/access করতে পারবে না।
- Authentication interface responsive হবে।
