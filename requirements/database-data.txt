# Dalimgari Website — Final Requirements

## 7. database-data.md

- Website-এর বিভিন্ন village information database-এ structuredভাবে সংরক্ষিত হবে।
- প্রয়োজন অনুযায়ী data আলাদা logical section/table-এ রাখা হবে।
- ভবিষ্যতে নতুন data type যুক্ত করা সম্ভব হতে হবে।
- User-owned data UID-এর সাথে সম্পর্কিত থাকবে।
- Database-level authorization ব্যবহার করে data access নিয়ন্ত্রণ করা হবে।
- সাধারণ user অন্য user-এর private data access করতে পারবে না।
- Admin-এর authorized access আলাদাভাবে নির্ধারিত হবে।
- Sensitive information শুধুমাত্র প্রয়োজনীয় authorized role access করতে পারবে।
- Database structure এমনভাবে তৈরি হবে যাতে ভবিষ্যতে feature বৃদ্ধি করা যায়।
