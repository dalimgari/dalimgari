# Dalimgari Website — Final Requirements

## 13. Admin Information.md

### Admin Information Show

Admin-এর নিচের তথ্য website-এ দেখানোর ব্যবস্থা থাকবে:

- Photo
- Name
- Email
- Phone Number
- Social Media
- Other Links

### Admin Information Edit

Admin নিচের তথ্য edit করতে পারবে:

- Photo
- Name
- Phone Number
- Social Media
- Other Links

### Email

- Admin Email display করা যাবে।
- Admin Information module থেকে Email edit করা যাবে না।

### Social Media

- Social media links আলাদা structured entries হিসেবে রাখা যাবে।
- প্রতিটি social media entry-এর platform এবং link থাকবে।

### Other Links

- প্রয়োজন অনুযায়ী একাধিক অন্যান্য link রাখা যাবে।
- প্রতিটি link-এর title এবং URL থাকবে।
