# Dalimgari Website — Final Requirements

## 21. Website Information.md

Admin Dashboard থেকে নিচের website information add, edit এবং remove/manage করা যাবে:

- Logo
- Website Name
- Slogan

### Rules

- Homepage Header এবং Hero-তে stored information ব্যবহার হবে।
- Website Name এবং Slogan পরিবর্তন করলে সংশ্লিষ্ট website sections updated information দেখাবে।
- Logo-এর জন্য supported image format এবং appropriate media storage ব্যবহার করতে হবে।
