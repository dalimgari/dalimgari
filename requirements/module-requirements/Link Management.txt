# Dalimgari Website — Final Requirements

## 14. Link Management.md

- পুরো website-এর জন্য একটি Global Link Management system থাকবে।
- Link add, edit এবং delete করা যাবে।
- Link-এর জন্য title এবং main URL থাকবে।
- Protocol না থাকলে system URL-এর শুরুতে `https://` যুক্ত করবে।
- `www.` বাধ্যতামূলকভাবে যোগ করা হবে না।
- URL-এর মূল domain শনাক্ত করা হবে।
- Domain অনুযায়ী icon সংগ্রহ করে database-এ সংরক্ষণ করা যাবে।
- একই domain-এর জন্য duplicate icon record তৈরি করা যাবে না।
- একই domain-এর link পরে যুক্ত হলে existing domain icon reuse করা হবে।
- Link delete করলে stored domain icon automatically delete হবে না।
- Footer-এ কোন links-এর icons দেখাবে তা Admin Dashboard থেকে নির্বাচন করা যাবে।
- Footer-এ icon দেখানোর জন্য নতুন করে URL দিতে হবে না; Link Management-এর existing link নির্বাচন করতে হবে।
