# Dalimgari Website — Final Requirements

## 18. Tab Management.md

- Tab create, edit এবং delete করা যাবে।
- প্রতিটি Tab-এর unique identity থাকবে।
- Tab নিজে কোনো content রাখবে না।
- Tab একটি নির্দিষ্ট Page-এর সাথে যুক্ত থাকবে।
- Homepage Body-তে enabled Tab প্রদর্শিত হবে।
- Tabs উপরের বাম দিক থেকে ডান দিকে সাজানো হবে।
- Disabled Tab Homepage-এ প্রদর্শিত হবে না।
- প্রথম enabled Tab default active হবে।
- Active Tab-এর আলাদা visual state থাকবে।
- Tab-এর order Admin Dashboard থেকে নিয়ন্ত্রণ করা যাবে।
- Tab delete করলে সংশ্লিষ্ট Page-এর behavior database relationship অনুযায়ী পরিচালিত হবে।
