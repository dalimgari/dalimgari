# Dalimgari Website — Final Requirements

## 9. security.md

- User-এর private information সুরক্ষিত রাখতে হবে।
- Password কখনো display করা যাবে না।
- Password plaintext হিসেবে database-এ রাখা যাবে না।
- সাধারণ user অন্য user-এর private information দেখতে পারবে না।
- Admin authorized user information দেখতে পারবে।
- সাধারণ user Admin-only functionality access করতে পারবে না।
- User নিজের role বা permission নিজে পরিবর্তন করতে পারবে না।
- Blocked user website-এর authenticated functionality ব্যবহার করতে পারবে না।
- Database access-এর ক্ষেত্রে proper authorization এবং Supabase Row Level Security (RLS) ব্যবহার করতে হবে।
- Sensitive operation-এর জন্য role/permission যাচাই করতে হবে।
- Client-side UI restriction-এর পাশাপাশি database/backend-level security থাকতে হবে।
