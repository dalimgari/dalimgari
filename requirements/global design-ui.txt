# Dalimgari Website — Final Requirements

## 3. global design-ui.md

- Website-এর design modern, clean এবং consistent হবে।
- Interface অপ্রয়োজনীয়ভাবে ভারী বা oversized হবে না।
- Button, input, icon এবং অন্যান্য UI element প্রয়োজন অনুযায়ী compact ও usable হবে।
- একই ধরনের UI element পুরো website-এ consistent design অনুসরণ করবে।
- Layout screen size অনুযায়ী পরিবর্তিত হবে।
- Visual hierarchy পরিষ্কার থাকবে।
- কোনো UI element content-এর প্রয়োজনের তুলনায় অপ্রয়োজনীয়ভাবে বড় হবে না।
